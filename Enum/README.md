# 💻 C++ Programming Practice

Welcome to my C++ Programming Practice repository!

This repository contains C++ programs that I have written
while learning and practising fundamental programming concepts.

The goal of this repository is to strengthen my programming
fundamentals, improve my problem-solving skills, and build
a strong foundation for Data Structures and Algorithms.

### 1. Arrays
- Array operations
- Traversing arrays

### 2. Enumerations (Enum)
- Basic enumerations
- Enum values
- Enum with switch statements
- Enum with functions

### 3. Structures
- Creating structures
- Accessing structure members
- Arrays of structures
- Passing structures to functions
- Nested structures

### 4. Pointers
- Pointer basics
- Accessing values using pointers
- Pointer arithmetic
- Pointers and functions
- Swapping values using pointers

### 5. Unions
- Basic unions
- Shared memory in unions
- Union size
- Unions with functions
- Unions inside structures
